Townlight / Townlight Boards

Board service needs clean records before it needs ceremony.

Townlight Boards v0.1.1 ships a foundation for board registry, term tracking, vacancy tracking, attendance review, optional database-backed roster records, notice/records export checklists, and an accessible sample UI aligned to civiccore==0.3.0.

Shipping v0.1.1

What ships

  • Sample board registry.
  • Term review plans.
  • Vacancy checklists.
  • Attendance review flags.
  • Optional roster persistence with CIVICBOARDS_ROSTER_DB_URL.
  • Notice and records export checklist.
  • Public sample UI at /civicboards.

What does not ship

Townlight Boards does not appoint members, remove members, publish official notices, provide legal advice, call live LLMs, write back to meeting systems, or replace a board system of record.

Repository

github.com/CivicSuite/civicboards

Dependency

Pinned to civiccore==0.3.0. Townlight Core remains dependency-only; it never imports from Townlight Boards.
