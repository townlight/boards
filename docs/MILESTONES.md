# Townlight Boards Milestones

## Milestone 0 - Reconciliation

Align repo docs and gates to the Townlight unified spec.

## Milestone 1 - Runtime Foundation

FastAPI package, health/root endpoints, Townlight Core pin, docs, tests, and release gate.

## Milestone 2 - board registry

Deterministic sample board registry and owner recommendation.

## Milestone 3 - term tracking

term tracking rows with explicit staff-verification boundary.

## Milestone 4 - vacancy tracking

vacancy tracking helper with human-review requirement.

## Milestone 5 - Attendance Review

Attendance review helper with staff-review requirement.

## Milestone 6 - Public-Records Export

Public-records export checklist for board records.

## Milestone 7 - Public UI and Release

Accessible public sample page at `/civicboards`, release artifacts, CI green, and umbrella compatibility update.
