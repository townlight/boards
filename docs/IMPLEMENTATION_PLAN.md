# Townlight Boards Implementation Plan

Townlight Boards v0.1.1 keeps the deterministic v0.1 foundation aligned to civiccore==0.3.0: runtime shell, sample board registry, term tracking, vacancy tracking helper, attendance review helper, notice and records export checklist, and public sample UI.

Later releases add local board catalog configuration, live board management platform integrations, Townlight Records file links, staff review queues, board execution workflow integrations, and production data governance.
