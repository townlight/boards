# CivicBoards Implementation Plan

CivicBoards v0.1.1 keeps the deterministic v0.1 foundation into a local-first runtime aligned to the published CivicCore v1.2.0 release wheel: runtime shell, sample board registry, term tracking, vacancy tracking helper, attendance review records, staff review queues, integration contracts, notice and records export checklist, and public/staff UI.

Later releases add local board catalog configuration, live board management platform integrations, CivicRecords file links, staff review queues, board execution workflow integrations, and production data governance.
